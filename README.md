# S.Y.L-APP-Emergency-Relief-App

## Overview

**S.Y.L APP** is a UI/UX prototype designed in Figma for an emergency response and public safety mobile application. The application aims to help users access critical information and essential services during emergency situations.

## Features

### SOS Emergency

The application includes an **SOS** feature that allows users to quickly access emergency-related services and information when needed.

### Interactive Map

The map provides real-time information to help users navigate safely by displaying:

* The user's current location.
* Nearby emergency shelters.
* Closed roads.
* Road obstacles and blocked areas.
* The shortest route to a selected shelter, either **on foot** or **by vehicle**.

### First Aid Guide

The application also includes a **First Aid** section containing essential first aid procedures. Each topic provides:

* Illustrative images.
* Step-by-step instructions.
* Clear descriptions explaining how each first aid technique should be performed correctly.

## Purpose

The goal of **S.Y.L APP** is to provide users with quick access to emergency resources, safe navigation during disasters, and basic first aid guidance through an intuitive and user-friendly mobile interface.
