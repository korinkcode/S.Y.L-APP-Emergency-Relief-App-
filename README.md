# S.Y.L-APP – Emergency Relief App

## Overview

**S.Y.L APP** is a UI/UX prototype designed in Figma for an emergency response and public safety mobile application. The application is designed to help users quickly access essential information and emergency services during natural disasters or crisis situations.

## Features

###  SOS Emergency

The application includes an **SOS** feature that allows users to quickly access emergency-related services and assistance.

### 🗺️ Interactive Map

The interactive map provides users with real-time navigation by displaying:

* The user's current location.
* Nearby emergency shelters.
* Closed roads.
* Road obstacles and blocked areas.
* The shortest route to the selected shelter, either **on foot** or **by vehicle**.

###  First Aid Guide

The application also includes a **First Aid** section containing essential first aid procedures. Each topic provides:

* Illustrative images.
* Step-by-step instructions.
* Clear descriptions explaining how each first aid technique should be performed correctly.

## Purpose

The goal of **S.Y.L APP** is to provide users with quick access to emergency resources, safe navigation during disasters, and basic first aid guidance through an intuitive and user-friendly mobile interface.
